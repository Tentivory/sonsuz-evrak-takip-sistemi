# SONSUZ EVRAK TAKİP SİSTEMİ

## Resmi Tanım

Bu proje, insanlığın en büyük sorunlarından biri olan **evrakların hiçbir zaman bitmemesi** problemini çözmek için değil, bu durumu bilimsel olarak modellemek için geliştirilmiştir.

Program, gerçek dünyadaki bürokratik süreçleri birebir simüle eder. 
Yani: Hiçbir şey ilerlemez. Ama her şey çok resmi görünür.

## Neden Bu Proje Var?

Çünkü bazen bir evrakın takip edilmesi, evrakın kendisinden daha önemlidir. 
Bazen de hiç önemli değildir. Ama yine de takip edilir.

Bu sistem, o duygusal ve zamansal boşluğu doldurmak için tasarlanmıştır.

## Kurulum

```bash
git clone https://github.com/Tentivory/sonsuz-evrak-takip-sistemi.git
cd sonsuz-evrak-takip-sistemi
python3 evrak_takip.py
```

## Kullanım

Programı çalıştırın. 
Sonra bekleyin. 
Sonra biraz daha bekleyin. 
Sonra fark edin ki program da sizi bekliyor.

Çıkmak için `Ctrl+C` yapabilirsiniz. 
Ama evrak çıkmaz.

## Özellikler

- Sonsuz döngü (evrak gibi)
- Rastgele bürokratik bahaneler
- Yavaş yazma efekti (gerçekçilik için)
- Hiçbir şeyin asla çözülmemesi
- Kayyum atandığında her şeyin sıfırlanması (gizli özellik)
